Complet : ID client OAuth Application Web, origine autorisée : dossiers privés + création du drive fusionné.
🔒 Tes drives sources ne sont jamais modifiés : lecture seule (drive.readonly). L'appli ne peut écrire que dans le dossier qu'elle crée elle-même (drive.file).
